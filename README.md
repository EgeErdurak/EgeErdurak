### Thesis: benchmarking what language models actually get right

**Goal-Oriented Timeline Generation: A Benchmark for Temporal Event Selection in
Large Language Models.** Grade 1.3, and being prepared as a full paper for
**ECIR 2027** (European Conference on Information Retrieval) on my supervisors'
recommendation, with me as lead author.

I built the evaluation pipeline end to end: 2,840 model/prompt/topic runs
(5 LLMs, 8 prompt conditions, 71 topics) against a reference corpus of 71
human-authored timelines containing 1,336 events. Timeline-aware ROUGE, a
deterministic failure taxonomy, and an LLM-as-a-judge layer validated against a
human audit. The model under test is kept separate from the model doing the
judging, and every run records its configuration, so results reproduce.

**[timeline-eval](https://github.com/EgeErdurak/goal-oriented-timeline-generation)**
is that pipeline, in Python.

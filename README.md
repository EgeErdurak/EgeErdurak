

Medieninformatik BSc student at **TU Dresden**, focused on **LLM evaluation and NLP** as final thesis.

I'm currently finishing my bachelor's thesis, **Benchmarking LLMs for Goal-Oriented Timeline Generation** — in practice, large-scale QA for AI outputs. I built an automated evaluation pipeline that executed **2,799 model–prompt–topic test runs** (5 LLMs × 8 prompt strategies × 70 topics) against a reference corpus of **70 timelines with 1,413 verified dated entries**, using timeline-aware ROUGE metrics, automated failure-taxonomy analysis, and LLM-as-a-judge hallucination scoring. The expected collequium date is 27th of August.

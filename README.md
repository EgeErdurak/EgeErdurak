# Hi, I'm Ege Erdurak 👋

Computer Science BSc student at **TU Dresden**, focused on **LLM evaluation and NLP**.

I'm currently finishing my bachelor's thesis, **Benchmarking LLMs for Goal-Oriented Timeline Generation** — in practice, large-scale QA for AI outputs. I built an automated evaluation pipeline that executed **2,959 model–prompt–topic test runs** (5 LLMs × 8 prompt strategies × 74 topics) against a reference corpus of **74 timelines with 1,522 verified dated entries**, using timeline-aware ROUGE metrics, automated failure-taxonomy analysis, and LLM-as-a-judge hallucination scoring.

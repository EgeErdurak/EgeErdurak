

Medieninformatik BSc student at **TU Dresden**, focused on **LLM evaluation and NLP** as final thesis.

I'm finishing my bachelor's thesis, Goal-Oriented Timeline Generation: A Benchmark for Temporal Event Selection in Large Language Models (submitted; colloquium 27 August 2026) — in practice, large-scale QA for AI outputs. I built an automated evaluation pipeline that executed 2,840 model–prompt–topic test runs (5 LLMs × 8 prompt conditions × 71 topics) against a reference corpus of 71 human-authored timelines with 1,336 reference events, using timeline-aware ROUGE metrics, deterministic failure-taxonomy analysis, and an LLM-as-a-judge layer validated against a human audit.
